## AI 时代怎样修改这条路线

**本路线重点：** 增加生成式/表征模型的对照实验与成本分析；保留偏差、反馈回路、排序和在线效果验证。

| 调整 | 建议 |
| --- | --- |
| 增加 | 生成 SQL 的核验；数据来源与许可；AI 评测数据；结果不确定性与解释 |
| 保留并扎实掌握 | 统计、口径、数据质量、因果边界和领域理解 |
| 减少重复训练 | 重复做图与模板报表；堆砌模型名称 |
| 必须识别的风险 | 虚构数据、错误连接、泄漏和因果误读被流畅语言掩盖 |

减少重复训练不等于跳过基础。AI 生成的结果仍需由提交者验证；具体课程与工作单位的工具规则优先。上述调整是规划建议，不能推出某个岗位将消失。相关参考：[Stanford CS229](https://see.stanford.edu/Course/CS229)。

## 代表作与能力验收

**项目：** 完整推荐链路与离线评估。

**关键验收：** 避免泄漏并解释离线在线差异。

- [ ] 需求、输入、输出和限制明确。
- [ ] 代码、数据或案例来源清楚，环境与步骤可复现。
- [ ] 记录个人贡献，能脱离 AI 解释关键机制并完成现场修改。
- [ ] 有针对本路线的测试、对照、用户验证或论证。
- [ ] 保留失败案例、误差或限制，而非只展示成功结果。
- [ ] 至少获得一次外部审查：实习、开源、导师、同伴或真实用户反馈。

这是一组能力证据，不是录用保证。具体简历和选拔准备见[求职、升学与作品集](../../docs/evidence-and-entry.md)。

## 后续发展与投入

可延伸到：**搜索、策略算法、ML 平台**。转向时先补目标路线的先修，不必从所有基础课重来。

本科阶段以初级入口或研究训练为目标；长远职级需要真实经验。

硬件路线先用仿真和学校设备；AI 路线先做小规模正确性实验并设算力预算；行业与研究路线先确认数据、导师或领域资源。不要只按路线名称购买培训或设备。
